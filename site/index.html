A mockup is a picture of the product. Tovi edits the product.

      

        
Every handoff loses something: a few pixels of spacing, a hover state, what happens with real data. By the time a design ships, someone else has rebuilt it from a picture, and the details drift.

        
With Tovi you skip the picture. Open the product your team already runs, fix the screen where it lives, and the fix reaches your developers as code they can review and merge.

Code a careful developer would write

        
Tovi links every element on screen to the line of JSX that made it, then changes that line through the syntax tree. No find-and-replace, no inline styles.

        
    
          
  • Uses your scale. 24 px becomes p-6, and your colour tokens stay tokens.
    • 
          
  • Finds where a style lives. Style tables, cva variants and @apply classes are changed at the source.
    • 
          
  • Asks how far to go. Only this one, every instance, or every variant.
    • 
          
  • Won’t break the build. Every change is checked before it’s written, and undone if the page breaks.
    •

Questions

      

        

          What does Tovi work with?
          
React apps built with Vite or Next.js 13 and newer, styled with Tailwind CSS v3. Tailwind v4 support is on the way.

        

        

          Can it change our code without anyone checking?
          
No. Tovi edits its own copy of your project. Nothing reaches your repository until you create the pull request, and your developers review it like any other.

        

        

          Where does our code go?
          
Your app runs on your own computer. When you use the AI, Tovi sends Claude the code and a screenshot of the part of the screen you’re asking about, using your key.

        

        

          Do developers need to install anything?
          
No. They get a normal pull request with a plain-language summary and before-and-after images.

        

        

          When can I use it?
          
We’re starting with a private beta for a small group of teams, then opening to everyone. Join the list and we’ll get in touch.
